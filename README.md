## Systems & Technical Background

- Distributed Systems & Storage: Append-only Bitcask write-ahead logs (WAL), monotonic fencing tokens, cache-aside strategies with Redis, database indexing, and idempotency guarantees.
- Backend Architecture: Layered NestJS and Express services, input boundary validation via Zod, connection pooling, and resilient retry policies with jitter.
- Frontend & Interaction: React 19, modern Angular SSR, native Arabic Right-to-Left (RTL) layout engineering with Cairo typography, and GPU-accelerated Three.js physics scenes.
- Foundations: C systems programming (custom `_printf`, POSIX `simple_shell`, Monty bytecode interpreter), UNIX process orchestration, and Linux environment administration.
