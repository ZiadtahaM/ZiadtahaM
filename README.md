## Engineering principles

> Build products that explain themselves: clear interfaces, typed boundaries, deliberate error states, and an honest distinction between working software and future scope.

I prioritize a source-first workflow: model the domain clearly, keep critical authorization on the server, validate inputs at API boundaries, and run automated checks before deployment. Project READMEs document current source boundaries so visitors can understand what is implemented without relying on inflated claims.
